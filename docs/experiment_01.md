# Experiment 1: Flutter & Dart Foundation

## Aim
To create the foundational structure for the Student Task Manager application using basic Flutter and Dart concepts.

## Objectives
- Initialize the Flutter project structure.
- Clean up unnecessary dependencies (e.g., removing unused packages).
- Set up a basic MaterialApp shell.

## Flutter Concepts Used
- Flutter project structure
- pubspec.yaml configuration
- Basic Dart concepts (classes, main() function)
- MaterialApp and StatelessWidget

## Implementation
The pubspec.yaml was cleaned up to remove any prohibited packages (like shared_preferences). A simple, clean lib/main.dart was created, featuring a StudentTaskManagerApp class that returns a MaterialApp with a placeholder home screen.

## Testing
Verified the app loads without errors and the foundation is intact using basic widget tests.

## Result
The base Flutter project for the Student Task Manager has been successfully created and verified.
